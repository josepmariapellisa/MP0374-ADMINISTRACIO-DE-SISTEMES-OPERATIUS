    PRÀCTICA COMPLETA: INSTAL·LACIÓ I CONFIGURACIÓ DE XAMPP AMB VIRTUALHOST SSL

    En aquesta pràctica hem dut a terme una instal·lació completa de XAMPP en un entorn Linux, configurant un entorn de desenvolupament web funcional amb servidors Apache i MySQL, a més de crear un virtualhost segur amb certificat SSL autosignat.

    RESUM D'ACCIONS REALITZADES:

    1. Descàrrega i instal·lació de XAMPP 8.2.12 amb PHP 8.2.12 per a arquitectura de 64 bits.
    2. Configuració del panell de control amb inici dels serveis Apache i MySQL.
    3. Creació de la base de dades "josep.cat" via phpMyAdmin amb usuari i contrasenya personalitzats.
    4. Configuració de virtualhost per al port 80 per al domini josep.cat amb accés local via /etc/hosts.
    5. Generació de certificat SSL autosignat amb OpenSSL per a connexions segures.
    6. Configuració de virtualhost per al port 443 amb activació de SSL i especificació dels certificats.
    7. Verificació del funcionament tant del virtualhost HTTP com HTTPS amb accés al dashboard de XAMPP.

    RESULTAT OBTINGUT:

    Ara tenim un entorn de desenvolupament web complet amb:

    • Servidor Apache funcionant als ports 80 i 443
    • Servidor MySQL operatiu amb base de dades "josep.cat"
    • Accés al domini josep.cat tant en HTTP com HTTPS
    • Certificat SSL autosignat per a connexions segures
    • Estructura de directoris organitzada a /opt/lampp/htdocs/josep.cat

    El sistema està llest per al desenvolupament i proves de pàgines web amb suport per a connexions segures HTTPS.

    Entrem a la pàgina oficial de descàrrega de XAMPP per Linux, busquem la versió 8.2.12 que inclou PHP 8.2.12 i fem clic al enllaç "Descargar (64 bit)" per baixar el fitxer de 151 MB.

    Li assignem permisos d'execució a l'arxiu .run baixat, utilitzant la comanda chmod +x i confirmem l'acció amb la contrasenya de sudo.

    En la finestra de selecció de components, marquem tant "XAMPP Core Files" com "XAMPP Developer Files" per a una instal·lació completa de totes les eines necessàries per al desenvolupament.

    Confirmem el directori d'instal·lació predeterminat /opt/lampp, que és la ubicació estàndard on XAMPP instal·larà tots els seus components per a un accés centralitzat.

    L'assistent d'instal·lació ens dona la benvinguda a XAMPP i comença a descomprimir i copiar els fitxers al sistema, mostrant una barra de progrés amb un 7% completat.

    Finalitzem l'assistent d'instal·lació de XAMPP amb èxit i marquem l'opció "Launch XAMPP" per iniciar el panell de control immediatament després de tancar l'assistent.

    Des del panell de control de XAMPP, comprovem que els servidors Apache i MySQL estan en funcionament correctament, mentre ProFTPD roman aturat, i tenim opcions per gestionar-los.

    Accedim al localhost i ens apareix la pàgina de benvinguda de XAMPP amb el dashboard, confirmant que Apache funciona correctament i està llest per servir contingut web.

    Obrim phpMyAdmin des de XAMPP per gestionar bases de dades, on podem veure la configuració de connexió amb el servidor local i les opcions principals de navegació per a l'administració.

    Creem una nova base de dades anomenada "josep.cat" amb el cotejament utf8mb4_general_ci des de l'opció "Crear base de datos" a phpMyAdmin.

    Afegim un nou usuari per a la base de dades amb nom "josep", host "%", contrasenya configurada i autenticació nativa de MySQL, garantint els permisos necessaris per a l'accés remot.

    Iniciem sessió a phpMyAdmin amb l'usuari "josep" creat prèviament, per verificar que es pot accedir correctament a la interfície d'administració de bases de dades amb aquestes credencials.

    Després de l'inici de sessió, veiem a phpMyAdmin que la base de dades "josep.cat" apareix llistada sota el servidor localhost, juntament amb les opcions de gestió disponibles per a l'usuari.

    Creem el directori per al virtualhost "josep.cat" dins de /opt/lampp/htdocs i assignem la propietat de l'usuari actual per garantir permisos d'escritura i lectura.

    Configurem el fitxer httpd-vhosts.conf amb nano, afegint un nou VirtualHost per a josep.cat al port 80, especificant el directori arrel, logs i permisos del directori perquè Apache pugui servir el contingut.

    Afegim les entrades "josep.cat" i "www.josep.cat" apuntant a 127.0.0.1 al fitxer /etc/hosts perquè el sistema resolgui aquests dominis localment, permetent accedir-hi sense necessitat de DNS.

    Reiniciem tots els serveis de XAMPP amb la comanda lampp restart, observant com s'aturen i tornen a iniciar Apache, MySQL i ProFTPD per aplicar els canvis de configuració realitzats.

    Creem un fitxer info.php dins de josep.cat i accedim al domini per veure la pàgina d'informació de PHP, confirmant que el virtualhost funciona i mostrant la versió 8.2.12.

    Generem unes noves claus de certificat mitjançant el Openssl, i creem un nou virtualhost.

    Afegim un nou bloc VirtualHost per al port 443 al fitxer httpd-vhosts.conf, configurant SSL amb els certificats creats i especificant els logs d'error i accés per a connexions segures.

    Verifiquem la configuració de SSL a httpd.conf per assegurar-nos que el mòdul està habilitat i que s'inclou el fitxer httpd-ssl.conf per a les connexions segures.

    Comprovem que el mòdul mod_ssl.so està carregat correctament al fitxer de configuració principal d'Apache, cosa essencial per habilitar suport SSL i TLS.

    Reiniciem tots els serveis de XAMPP amb la comanda lampp restart, observant com s'aturen i tornen a iniciar Apache, MySQL i ProFTPD per aplicar els canvis de configuració realitzats.

    Accedim a www.josep.cat i veiem que es carrega el dashboard de XAMPP correctament a través del navegador, confirmant que el domini resol localment i Apache respon, pero no podem obtindre el resultat de https direccionat pel port 443.

    SOLUCIO DEFINITIVA CERTIFICAT CA PROPIA HTTPS

    Creem una Autoritat Certificadora pròpia i generem certificats SSL per al domini josep.cat, primer generem la CA arrel amb clau RSA 2048, després creem una petició de certificat per al servidor i signem el certificat amb la nostra CA, finalment instal·lem el certificat CA al sistema i configurem els certificats per al servidor web LAMPP.

    Preparem la base de dades de certificats NSS per al navegador Chrome, instal·lem libnss3-tools i creem el directori .pki/nssdb on s'emmagatzemaran els certificats de confiança per poder importar la nostra CA pròpia i evitar errors de seguretat al navegador quan accedim al lloc web amb HTTPS.

    Importem la nostra CA al magatzem de certificats del navegador utilitzant certutil, assignem les opcions de confiança "CT,C,C" per al certificat arrel i ajustem els permisos del directori .pki perquè l'usuari pellisa pugui gestionar els certificats correctament al Chrome.

    Activem el mòdul SSL i la configuració HTTPS al servidor LAMPP, descomentem les línies del mòdul SSL i la inclusió del fitxer httpd-ssl.conf al httpd.conf principal, preparant l'entorn per habilitar connexions segures amb el certificat que hem generat per al domini.

    Configurem el virtual host SSL al fitxer httpd-ssl.conf del servidor LAMPP, especifiquem el port 443, el nom del servidor josep.cat, els logs, i indiquem les rutes del certificat i clau generats per a les connexions HTTPS segures al lloc web.

    Accedim a phpMyAdmin a través del domini josep.cat/phpmyadmin/, la pàgina es carrega correctament mostrant que el servidor LAMPP està funcionant i podem iniciar sessió per gestionar bases de dades dins de la infraestructura web del nostre entorn corporatiu.

    Accedim a la pàgina de benvinguda de XAMPP a josep.cat, confirmant que el servidor LAMPP està operatiu i servint contingut web correctament, amb accés a phpMyAdmin, PHPInfo i la documentació bàsica del servidor web.

    Verifiquem els detalls del certificat SSL al navegador, confirmem que està emès per la nostra CA pròpia ASIX_Local_Root_CA per al domini josep.cat, amb validesa d'un any i correctament configurat per a les connexions HTTPS al lloc web del servidor LAMPP.
