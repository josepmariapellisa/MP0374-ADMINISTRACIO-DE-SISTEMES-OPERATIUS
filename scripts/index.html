    Arxius de configuració automàtica

    Scripts per configurar automàticament el servidor i els clients Ansible.

    Resum del projecte

    El conjunt de scripts del projecte permet una configuració totalment automatitzada. Disposem d'un script principal per al servidor (install_server.sh) que prepara tot l'ecosistema Flask i Ansible, i d'scripts de "bootstrap" per als clients Linux (linux_client.sh) i Windows (windows_client.ps1) que configuren els protocols de comunicació necessaris (SSH i WinRM respectivament) per a que el servidor pugui gestionar-los sense intervenció manual.

    install_server.sh

    Script d'instal·lació del servidor Ansible Web Manager.

    Com instal·lar el servidor

    Aquest fitxer és el més important per començar. S'encarrega de preparar tot l'ordinador principal perquè pugui controlar la resta:

    1. Posa les eines al seu lloc: Instal·la programes com Python i Ansible.
    2. Prepara les claus: Crea les claus de seguretat que permeten al servidor entrar als altres ordinadors.
    3. Crea la pàgina web: Configura tot el necessari perquè puguis veure el panell de control al navegador.
    4. Fes que s'engegui sol: Configura un servei perquè el gestor estigui actiu sempre que l'ordinador estigui encès.
    # Anar al directori del projecte
cd ~/ansible_project

# Executar com a root
sudo ./install_server.sh

    El que fa

    L'execució d'aquest script realitza una sèrie de passos encadenats: primer verifica els privilegis de root per poder realitzar canvis al sistema, després actualitza els repositoris i instal·la tant els paquets del sistema com les llibreries de Python requerides. Posteriorment, s'encarrega de la part de seguretat generant les claus SSH si no existeixen, configura el fitxer global d'Ansible, prepara la base de dades d'usuaris de l'aplicació web i finalment registra el servei systemd per garantir que l'aplicació s'iniciï cada vegada que s'engega l'ordinador.

    Fitxers Creats/Modificats

    Fitxer Descripció
    ~/.ssh/ansible_lab Clau privada SSH (generada o existent)
    ~/.ssh/ansible_lab.pub Clau pública SSH
    ~/.ssh/config Configuració SSH
    ansible.cfg Configuració d'Ansible
    inventories/inventory.ini Inventari d'hosts
    group_vars/alumnes/apps.yml Variables per defecte
    webapp/users.json Usuaris de la web
    /etc/systemd/system/ansible-web-manager.service Servei systemd

    Claus SSH

    El script comprova si existeix la clau ~/.ssh/ansible_lab: - Si existeix: La reutilitza (no la sobreescriu) - Si no existeix: Genera una nova clau ed25519

    Després mostra la clau pública per copiar-la al linux_client.sh.

    Variables d'Entorn

    Pots personalitzar l'execució amb variables d'entorn:

    # Usuari propietari del projecte
export ANSIBLE_USER="elmeu_usuari"

# Nom de la clau SSH
export SSH_KEY_NAME="la_meva_clau"

# Executar
sudo ./install_server.sh

    Servei Systemd

    Després de la instal·lació, pots gestionar l'aplicació com a servei:

    # Iniciar
sudo systemctl start ansible-web-manager

# Parar
sudo systemctl stop ansible-web-manager

# Veure estat
sudo systemctl status ansible-web-manager

# Veure logs
sudo journalctl -u ansible-web-manager -f

# Habilitar inici automàtic
sudo systemctl enable ansible-web-manager

    Troubleshooting

    Error: "python3: command not found"

    sudo apt install python3 python3-pip

    Error: "clau SSH no trobada"

    # Generar manualment la clau
ssh-keygen -t ed25519 -f ~/.ssh/ansible_lab -N ""

    La web no funciona

    # Veure logs del servei
sudo journalctl -u ansible-web-manager -n 50

# O executar manualment
cd ~/ansible_project/webapp
python3 app.py

    Configuració del client Linux

    Aquest script serveix per preparar els ordinadors dels alumnes que usen Linux (com Ubuntu). El que fa bàsicament és obrir una porta segura perquè el servidor pugui entrar-hi a treballar:

    1. Actualitza la llista de programes: S'assegura que l'ordinador sàpiga d'on baixar les eines.
    2. Crea un usuari especial: Crea l'usuari "ansible" que és el que fa tota la feina bruta.
    3. Posa la clau de seguretat: Afegeix el codi secret del servidor perquè pugui entrar sense demanar contrasenya.

    Contingut del Script

    #!/usr/bin/env bash
set -euo pipefail

# Bootstrap Ansible Client (Ubuntu)
# Executa-ho AL CLIENT amb un usuari amb sudo (ex: alumne) o com root.
# Aquest script configura l'usuari "ansible" i la clau pública fixa per accés SSH.

ANSIBLE_USER="ansible"

PUBKEY='ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIBpIdwr5ssTSLAGS0l5OWXE2M3Ju4FtdNyLNA/phvVY8 ansibleadmin@server'

# --- helpers ---
need_root() {
  if [[ "${EUID:-$(id -u)}" -ne 0 ]]; then
    echo "Has d'executar com root o amb sudo:"
    echo "  sudo $0"
    exit 1
  fi
}

ensure_pkg() {
  local pkg="$1"
  if ! dpkg -s "$pkg" >/dev/null 2>&1; then
    apt-get install -y "$pkg"
  fi
}

# --- main ---
need_root

echo "[1/4] Actualitzant índex APT..."
apt-get update -y

echo "[2/4] Instal·lant SSH server i sudo..."
ensure_pkg "sudo"
ensure_pkg "openssh-server"

echo "[3/4] Activant servei SSH..."
systemctl enable --now ssh

echo "[4/4] Creant usuari ${ANSIBLE_USER} (si cal)..."
if ! id "${ANSIBLE_USER}" >/dev/null 2>&1; then
  adduser --disabled-password --gecos "" "${ANSIBLE_USER}"
fi

echo "[5/5] Donant permisos sudo (NOPASSWD) a ${ANSIBLE_USER}..."
usermod -aG sudo "${ANSIBLE_USER}"
echo "${ANSIBLE_USER} ALL=(ALL) NOPASSWD:ALL" > "/etc/sudoers.d/${ANSIBLE_USER}"
chmod 440 "/etc/sudoers.d/${ANSIBLE_USER}"

echo "[6/6] Configurant authorized_keys..."
HOME_DIR="$(getent passwd "${ANSIBLE_USER}" | cut -d: -f6)"
install -d -m 700 -o "${ANSIBLE_USER}" -g "${ANSIBLE_USER}" "${HOME_DIR}/.ssh"
touch "${HOME_DIR}/.ssh/authorized_keys"
chown "${ANSIBLE_USER}:${ANSIBLE_USER}" "${HOME_DIR}/.ssh/authorized_keys"
chmod 600 "${HOME_DIR}/.ssh/authorized_keys"

# Afegir la clau només si no hi és ja
grep -qxF "${PUBKEY}" "${HOME_DIR}/.ssh/authorized_keys" || echo "${PUBKEY}" >> "${HOME_DIR}/.ssh/authorized_keys"

echo "✅ Client preparat."
echo "Prova des del servidor:"
echo "  ssh -i ~/.ssh/ansible_lab ${ANSIBLE_USER}@<IP_CLIENT> 'whoami && hostname'"

    Ús

    # Opció 1: Descarregar i executar
wget http://192.168.1.115/linux_client.sh
chmod +x linux_client.sh
sudo ./linux_client.sh

# Opció 2: Executar directament
curl -s http://192.168.1.115/linux_client.sh | sudo bash

    El que fa

    1. Actualitza APT: apt-get update -y
    2. Instal·la paquets: openssh-server, sudo
    3. Activa SSH: systemctl enable --now ssh
    4. Crea usuari: ansible sense password
    5. Configura sudo: Crea /etc/sudoers.d/ansible amb NOPASSWD
    6. Afegeix clau: Afegeix la clau pública a ~ansible/.ssh/authorized_keys

    Clau SSH Utilitzada

    ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIBpIdwr5ssTSLAGS0l5OWXE2M3Ju4FtdNyLNA/phvVY8 ansibleadmin@server

    ⚠️ Important: Canvia aquesta clau per la teva clau real!

    Com Canviar la Clau

    # Al servidor, genera nova clau
ssh-keygen -t ed25519 -f ~/.ssh/ansible_lab -N ""

# Copia la clau pública
cat ~/.ssh/ansible_lab.pub

# Actualitza linux_client.sh amb la nova clau
PUBKEY='ssh-ed25519 LA_TEVA_CLAU ansibleadmin@server'

    Verificació

    # Des del servidor, prova connectar
ssh -i ~/.ssh/ansible_lab ansible@192.168.203.201 'whoami && hostname'

# Ha de retornar:
# ansible
# pc201

    Configuració del client Windows

    Windows és una mica més especial, per això fem servir un arxiu de PowerShell que fa aquestes tasques:

    1. Obre el protocol de comunicació: Activa el sistema WinRM que permet rebre ordres de lluny.
    2. Crea l'usuari d'administració: Crea un compte anomenat "ansible" amb permisos per fer canvis al sistema.
    3. Obre el mur de seguretat: Configura el tallafocs (firewall) perquè el servidor pugui enviar ordres pels ports correctes.

    Contingut del Script

    # Bootstrap Ansible Client (Windows)
# Executa com Administrador

$ErrorActionPreference = "Stop"

$ANSIBLE_USER = "ansible"
$ANSIBLE_PASSWORD = "Ansible123!"

Write-Host "[1/5] Habilitant WinRM..." -ForegroundColor Cyan
Enable-PSRemoting -Force
Set-Item WSMan:\localhost\Client\TrustedHosts "*" -Force

Write-Host "[2/5] Creant usuari $ANSIBLE_USER..." -ForegroundColor Cyan
$SecurePass = ConvertTo-SecureString $ANSIBLE_PASSWORD -AsPlainText -Force
New-LocalUser -Name $ANSIBLE_USER -Password $SecurePass -FullName "Ansible User" -Description "Ansible management user" -ErrorAction SilentlyContinue

Write-Host "[3/5] Afegint a grup Administradors..." -ForegroundColor Cyan
Add-LocalGroupMember -Group "Administrators" -Member $ANSIBLE_USER -ErrorAction SilentlyContinue

Write-Host "[4/5] Configurant firewall..." -ForegroundColor Cyan
New-NetFirewallRule -DisplayName "WinRM HTTP" -Direction Inbound -LocalPort 5985 -Protocol TCP -Action Allow -ErrorAction SilentlyContinue
New-NetFirewallRule -DisplayName "WinRM HTTPS" -Direction Inbound -LocalPort 5986 -Protocol TCP -Action Allow -ErrorAction SilentlyContinue

Write-Host "[5/5] Configurant WinRM per autenticació básica..." -ForegroundColor Cyan
Set-Item WSMan:\localhost\Client\AllowUnencrypted -Value $true -Force
Set-Item WSMan:\localhost\Service\Auth\Basic -Value $true -Force

Write-Host "✅ Client Windows preparat." -ForegroundColor Green
Write-Host "Usuari: $ANSIBLE_USER"
Write-Host "Password: $ANSIBLE_PASSWORD"

    Ús

    # Opció 1: Descarregar i executar
Invoke-WebRequest -Uri http://192.168.1.115/windows_client.ps1 -OutFile C:\windows_client.ps1
PowerShell -ExecutionPolicy Bypass -File C:\windows_client.ps1

# Opció 2: Executar directament
Invoke-Command -ScriptBlock { irm http://192.168.1.115/windows_client.ps1 | iex }

    El que fa

    1. Habilita WinRM: Enable-PSRemoting -Force
    2. Configura TrustedHosts: Permet connexions de qualsevol host
    3. Crea usuari: ansible amb password Ansible123!
    4. Afegeix a Administradors: Permet executar comandes amb privilegis
    5. Configura firewall: Obre ports 5985 (HTTP) i 5986 (HTTPS)

    Verificació

    # Des del servidor Windows, prova connectar
Test-WSMan -ComputerName <IP_CLIENT> -Authentication Basic

# O des de Linux amb Ansible
ansible win-pc01 -m win_ping -i inventory.ini

    Comparativa Linux vs Windows

    Característica Linux Windows
    Protocol SSH WinRM
    Usuari ansible ansible
    Autenticació Clau pública (ed25519) Password bàsic
    Port 22 5985 (HTTP), 5986 (HTTPS)
    Privilegis sudo NOPASSWD Grup Administradors
    Firewall No cal Obre ports WinRM

    Solució de Problemes

    Linux: Error "Permission denied"

    # Verifica usuari
id ansible

# Verifica sudo
sudo -l -U ansible

# Verifica clau SSH
cat ~ansible/.ssh/authorized_keys

    Linux: Error "Connection refused"

    # Verifica SSH
systemctl status ssh

# Verifica port
ss -tlnp | grep :22

# Reinicia SSH
systemctl restart ssh

    Windows: Error "WinRM connection"

    # Verifica WinRM
Test-WSMan -ComputerName localhost

# Verifica firewall
Get-NetFirewallRule -DisplayName "*WinRM*"

# Reinicia WinRM
Restart-Service WinRM

    Windows: Error "Access Denied"

    # Verifica usuari
Get-LocalUser -Name ansible

# Verifica grups
Get-LocalGroupMember -Group Administrators

# Verifica WinRM auth
Get-Item WSMan:\localhost\Service\Auth

    Seguretat

    Recomanacions

    1. Canviar la clau SSH: No utilitzis la clau de l'exemple
    2. Canviar el password: No utilitzis Ansible123! en producció
    3. Restringir TrustedHosts: En lloc de *, posar la IP del servidor
    4. Usar IPS: Només permetre connexions des de la IP del servidor Ansible
    5. Auditar: Revisar regularment els accessos

    Linux: Hardening

    # Restringir accessos SSH
echo "ansible ALL=(ALL) NOPASSWD: /usr/bin/apt, /usr/bin/dpkg" > /etc/sudoers.d/ansible

# Només permetre des del servidor
echo "sshd: 192.168.1.115" >> /etc/hosts.allow
echo "sshd: ALL" >> /etc/hosts.deny

    Windows: Hardening

    # Restringir TrustedHosts
Set-Item WSMan:\localhost\Client\TrustedHosts "192.168.1.115" -Force

# Requereix HTTPS en lloc de HTTP
Set-Item WSMan:\localhost\Service\AllowUnencrypted -Value $false -Force
Set-Item WSMan:\localhost\Service\Auth\Kerberos -Value $true -Force
