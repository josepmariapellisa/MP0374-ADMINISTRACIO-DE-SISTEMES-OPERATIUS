    Guia d'Ús - Per a No Tècnics

    Guia pas a pas per utilitzar l'Ansible Web Manager.

    Introducció

    Aquesta eina et permet controlar tots els ordinadors de l'aula des d'una pàgina web centralitzada. En lloc d'anar ordinador per ordinador, pots realitzar accions de forma massiva amb un sol clic. El servidor és com el "cap" que envia ordres a la resta d'equips que anomenem "clients".

    Quines accions pots realitzar? - Instal·lar programes a tots els ordinadors alhora. - Bloquejar l'accés a Internet per fer exàmens sense distraccions. - Bloquejar el teclat i el ratolí dels alumnes per explicar alguna cosa important. - Enviar fitxers o exercicis a tota la classe de cop. - Consultar quins programes té instal·lat cada alumne.

    Com iniciar el sistema

    Com preparar el servidor

    Per posar en marxa el gestor, segueix aquests passos al terminal del servidor:

    1. Obre el terminal: Inicia sessió amb el teu usuari habitual.
    2. Entra al directori del projecte: Utilitza cd ~/ansible_project.
    3. Activa el motor: Escriu source venv/bin/activate. Això prepara les eines de Python necessàries.
    4. Engega la web: Executa python3 app.py.
    5. Accedeix a la web: Obre un navegador i entra a http://localhost:8080.

    O des d'un altre ordinador de la xarxa:

    http://192.168.1.115:8080

    (Canvia 192.168.1.115 per la IP del teu servidor)

    Com iniciar sessió (Login)

    Camp Què posar
    Usuari profe
    Contrasenya profe

    El procés d'entrada és molt senzill: primer cal assegurar-se que el servidor estigui engegat, després obrim el navegador en qualsevol dispositiu de la mateixa xarxa i, finalment, introduïm les nostres credencials de professor per accedir al panell de control principal de l'aula.

    Gestió d'usuaris

    Afegir un usuari nou

    Per què? Per permetre que altres professors utilitzin el sistema.

    Pas 1: Anar al fitxer d'usuaris

    El fitxer està a: ~/ansible_project/webapp/users.json

    Pas 2: Edita el fitxer

    # Obre el fitxer amb un editor de text
nano ~/ansible_project/webapp/users.json

    Pas 3: Afegeix el nou usuari

    El fitxer té aquest aspecte:

    {
  "profe": {
    "password": "hash_aleatori",
    "role": "admin",
    "created_at": "2024-03-12T10:00:00"
  }
}

    Per afegir un usuari nou (per exemple, "anna"), afegeix això:

    {
  "profe": {
    "password": "hash_aleatori",
    "role": "admin",
    "created_at": "2024-03-12T10:00:00"
  },
  "anna": {
    "password": "hash_aleatori",
    "role": "admin",
    "created_at": "2024-03-12T10:30:00"
  }
}

    Però com conec el hash de la contrasenya?

    Pas 4: Generar contrasenya amb Python

    Executa això al terminal:

    cd ~/ansible_project/webapp
python3 << 'EOF'
import hashlib
import json
import datetime

nom_usuari = "anna"                # El nom de la persona nova
contrasenya = "password123"        # La clau que farà servir

hash_contrasenya = hashlib.sha256(contrasenya.encode()).hexdigest()

print(f\"Usuari: {nom_usuari}\")
print(f\"Password: {contrasenya}\")
print(f\"Hash: {hash_contrasenya}\")
print(f\"\")
print(f\"Copia això al users.json:\")
print(f'  \"{nom_usuari}\": {{\')
print(f'    \"password\": \"{hash_contrasenya}\",')
print(f'    \"role\": \"admin\",')
print(f'    \"created_at\": \"{datetime.datetime.now().isoformat()}\"')
print(f'  }},')
EOF

    Això t'ho genera tot:

    Usuari: anna
Password: password123
Hash: 8192e0c8b...

Copia això al users.json:
  "anna": {
    "password": "8192e0c8b...",
    "role": "admin",
    "created_at": "2024-03-12T10:30:00"
  },

    1. Copia al fitxer: Copia el text de dalt i afegeix-lo al users.json.

    2. Guarda i surt: A nano, prem Ctrl + O (guardar), Enter i Ctrl + X (sortir).

    Canviar contrasenya d'un usuari

    Repeteix els passos anteriors, però amb el mateix nom d'usuari i la nova contrasenya. El hash nou substituirà l'antic.

    Afegir equips

    Com utilitzar l'escaneig automàtic

    L'escaneig et permet trobar ordinadors a la xarxa sense haver d'escriure les seves adreces una per una:

    1. Prem el botó Escanejar: Està situat a la part superior de la pantalla.
    2. Selecciona l'aula: Tria el nom o el rang de xarxa que vulguis revisar (per exemple, Aula 203).
    3. Inicia la cerca: Prem el botó blau per començar. El sistema enviarà un petit missatge a cada ordinador per veure si respon.
    4. Tria els equips: Quan surti la llista, marca la casella dels ordinadors que vulguis incloure. Fixa't que els verds són els que ja estan a punt.
    5. Desa els canvis: Prem "Afegir seleccionats" i ja els tindràs a la pantalla principal per sempre.

    I ja estan! Apareixeran a la llista principal.

    Com afegir equips manualment

    Si preferies afegir un ordinador concret pel seu nom:

    1. Prem Afegir client: Està al costat de la lupa d'escaneig.
    2. Escriu les dades: Posa un nom fàcil de reconèixer (com "pc-01") i la seva adreça IP.
    3. Selecciona el sistema: Indica si és un ordinador amb Linux o amb Windows.
    4. Desa el client: L'ordinador apareixerà immediatament a la graella principal.

    Instal·lar programes

    Aquesta funció serveix per posar programari nou als ordinadors dels alumnes sense haver d'anar un per un. El servidor s'encarrega d'enviar i instal·lar el programa automàticament.

    Com instal·lar programes

    Pots enviar programes a molts ordinadors a la vegada seguint aquests passos:

    1. Tria els ordinadors: Marca els quadres dels equips on vulguis fer canvis.
    2. Selecciona el que necessites: Veuràs una llista de programes (VLC, Firefox, etc.). Marca els que falten.
    3. Aplica els canvis: Prem el botó "Aplicar". El servidor es connectarà a cada un i farà la instal·lació sense que tu hagis de fer res més.
    Programa Per a què serveix
    VLC Reproduir vídeos
    GIMP Editar imatges
    FileZilla Transferir fitxers FTP
    Firefox Navegar per internet
    ... ...
    1. Aplica la configuració: Prem el botó gran de sota de tot.
    2. Espera el resultat: Veuràs una barra de progrés. Quan acabi, sortirà un missatge de color verd dient que tot ha anat bé.

    Com activar i desactivar el Mode Examen

    Aquesta eina permet que els alumnes estiguin concentrats durant les proves. En activar-la, el sistema impedeix que puguin entrar a pàgines web com jocs, xarxes socials o ajudants de treball (IA).

    Seguiu aquests passos: 1. Selecciona els alumnes: Tria qui ha de fer el bloqueig. 2. Activa el silenci digital: Prem el botó vermell. Això posa un mur virtual que només deixa passar el que és necessari per l'examen. 3. Acaba l'examen: Quan hagin acabat, selecciona els mateixos alumnes i prem el botó verd de restaurar. L'ordinador tornarà al seu estat normal de navegació immediatament.

    Bloquejar webs

    A part del Mode Examen, pots bloquejar webs concretes.

    Pas 1: Ves a la pàgina de l'ordinador

    Fes clic a un ordinador (ex: pc201).

    Pas 2: Selecciona la pestanya "Webs"

    A la part superior de la pàgina de l'ordinador.

    Pas 3: Trieu les webs

    Pots: - Bloquejar categories: IA, Xarxes Socials, Jocs... - Bloquejar webs concretes: Escriu els dominis (ex: marca.es,elpais.com)

    1. Blocar: Prem el botó de bloquejar.

    Per tornar-ho a deixar com estava, només cal prémer el botó de desbloquejar tot.

    Com bloquejar el teclat i el ratolí

    Si vols que la classe s'aturi i miri a la pissarra:

    1. Selecciona els ordinadors: Tria tota la classe o només uns quants.
    2. Bloqueja l'entrada: Prem el botó d'inhabilitar perifèrics. El ratolí deixarà de moure's al moment.
    3. Torna a la feina: Quan hagis acabat l'explicació, prem el botó de desbloquejar i tot funcionarà com abans.

    Altres funcions

    Veure què té instal·lat un ordinador

    1. Fes clic a un ordinador
    2. Veuràs la llista de programes
    3. Pots filtrar per categoria:
    4. Jocs
    5. Navegadors
    6. Xarxes socials
    7. Programació

    Bloquejar un programa

    1. Fes clic a un ordinador
    2. Troba el programa
    3. Prem el botó de bloquejar.

    El programa encara és there, però no es pot executar.

    Env fitxers

    1. Selecciona els ordinadors
    2. A la secció "Transferència de Fitxers", tria el fitxer
    3. Prem el botó d'enviar als ordinadors.

    El fitxer s'envia a /var/tmp/ (Linux) o C:\ansible_temp\ (Windows).

    Problemes comuns

    No puc fer login

    Problema: Et diu "Credencials incorrectes"

    Solució: 1. Comprova que l'usuari és profe i la contrasenya profe 2. Si no funcion, cal restaurar les credencials:

    rm ~/ansible_project/webapp/users.json
# Reinicia l'aplicació

    No es connecta als ordinadors

    Problema: "Connection refused" o "Permission denied"

    Solució: 1. Comprova que els ordinadors estan encesos 2. Comprova que tenen la xarxa connectada 3. Reinstal·la el client:

    wget http://192.168.1.115/linux_client.sh
sudo ./linux_client.sh

    Mode Examen no funciona

    Problema: Els alumnes encara poden navegar

    Solució: 1. Comprova que els ordinadors són Linux (Windows no suportat) 2. Torna-ho a provar 3. Si encara no funciona, reinicia els ordinadors

    La pàgina no carrega

    Problema: No pots obrir localhost:8080

    Solució: 1. Comprova que l'aplicació està iniciada:

    ps aux | grep app.py
    1. Si no surt res, inicia-la:
    cd ~/ansible_project/webapp
python3 app.py

    Glossari

    Paraula Significat
    Host Un ordinador/client
    VLAN Una xarxa / aula (ex: 192.168.203.x)
    Inventari La llista d'ordinadors controlats
    Playbook Un conjunt d'accions per fer als ordinadors
    Mòdul Una eina d'Ansible (ex: instal·lar programes)
    SSH Protocol per connectar-se als ordinadors
    ** sudo** Executar com a administrador

    Necessites ajuda?

    1. Mira el fitxer docs/troubleshooting.md per problemes més complexos
    2. Parla amb l'administrador del sistema
    3. Revisa els logs: sudo journalctl -u ansible-web-manager -f
