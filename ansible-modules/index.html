    Eines de treball d'Ansible

    Documentació completa dels mòduls d'Ansible utilitzats al projecte.

    Eines per a Linux

    En el món d'Ansible, anomenem "mòduls" a les eines específiques que fan feines concretes. És com una caixa de brossa on cada eina serveix per a una cosa diferent.

    L'eina de comandes (shell)

    Aquesta és l'eina més flexible. Permet escriure comandes directament a l'ordinador de l'alumne com si hi fossis davant. La fem servir per a gairebé tot: bloquejar webs, apagar el teclat o llistar fitxers.

    • Funcionament: Tu escrius la comanda i Ansible s'encarrega d'enviar-la i portar-te la resposta.
    • Seguretat: Cal vigilar que la comanda estigui ben escrita per no fer canvis que no toquen.

    Ús al Projecte

    # A app.py - Executar una comanda de shell
success, stdout, stderr = run_ansible_adhoc(
    hostname,
    "shell",
    "whoami",
    ssh_user="ansible",
    platform="linux"
)

    # A playbooks - Exemple d'ús
- name: Llistar paquets instal·lats
  ansible.builtin.shell:
    cmd: dpkg -l
  register: pkg_list

- name: Executar amb chdir
  ansible.builtin.shell:
    cmd: ./install.sh
    chdir: /opt/myapp

- name: Només executar si no existeix el fitxer
  ansible.builtin.shell:
    cmd: wget http://example.com/file.tar.gz
    creates: /tmp/file.tar.gz

    Cases d'Ús al Projecte

    Funcionalitat Comanda Descripció
    Bloquejar web sed -i '/# BLOCKED_IES/d' /etc/hosts Esborra entrades bloquejades
    Mode Examen iptables -F OUTPUT Neteja regles de firewall
    Bloquejar programa which steam \| xargs chmod -x Elimina bit d'execució
    Desbloquejar programa which steam \| xargs chmod +x Afegeix bit d'execució
    Entrada control xinput disable 2 Bloqueja teclat/ratolí
    Llistar paquets dpkg -l Llista paquets instal·lats
    Detecció apps dpkg -S '/usr/share/applications/*.desktop' Busca aplicacions GUI

    Millor pràctica: Quan possible, usar command o mòduls específics.

    L'eina d'instal·lació (apt)

    Aquesta eina serveix per gestionar els programes instal·lats. És la que fa que apareguin programes nous com VLC o Firefox als ordinadors dels alumnes.

    • Tasques: Pot instal·lar coses noves (present), esborrar programes que no volem (absent) o actualitzar-los tots a l'última versió (latest).
    • Avantatges: No cal saber com es baixa el programa, només cal dir-li el nom i Ansible s'encarrega de tot.

    Ús al Projecte

    # playbooks/apps.yml
- name: Instal·lar aplicacions del catàleg
  apt:
    name: "{{ item }}"
    state: present
    update_cache: yes
  loop: "{{ selected_apps }}"

    Estats del Paquet

    Estat Descripció Exemple
    present Paquet instal·lat apt: name=vlc state=present
    absent Paquet eliminat apt: name=vlc state=absent
    latest Última versió apt: name=vlc state=latest
    build-dep Dependències de construcció apt: name=vlc state=build-dep

    Consideracions

    • Requereix become: true (privilegis root)
    • update_cache=yes pot ser lent, usar amb cache_valid_time
    • Només funciona a Debian/Ubuntu (usar dnf, yum, pacman per altres distribucions)

    L'eina de comandes simples (command)

    És molt semblant a l'eina shell, però més segura. La fem servir quan només volem executar una comanda senzilla sense fer coses complicades com ajuntar moltes comandes en una sola línia.

    Ús Recomanat

    # ✅ BON: Usar command per comandes simples
- name: Comprovar espai de disc
  ansible.builtin.command:
    cmd: df -h
  register: disk_space

# ⚠️ MILLOR EVITAR: Usar shell si no cal
- name: Descarregar fitxer
  ansible.builtin.shell:
    cmd: wget http://example.com/file.tar.gz | tar xzf -

# ✅ MILLOR: Usar mòduls específics
- name: Descarregar fitxer
  ansible.builtin.get_url:
    url: http://example.com/file.tar.gz
    dest: /tmp/file.tar.gz

    ansible.builtin.systemd

    Gestiona serveis systemd.

    Paràmetres Principals

    Paràmetre Tipus Descripció
    name string Nom del servei
    state string started, stopped, restarted, reloaded
    enabled bool Habilita/deshabilita inici automàtic
    daemon_reload bool Recarrega configuració systemd

    Ús al Projecte

    # Activar SSH al client
- name: Assegurar que SSH estigui actiu
  ansible.builtin.systemd:
    name: ssh
    state: started
    enabled: yes

    Estats del Servei

    ansible.builtin.copy

    Copia fitxers des de la màquina controladora als hosts remots.

    Paràmetres Principals

    Paràmetre Tipus Descripció
    src string Fitxer origen (controladora)
    dest string Fitxer destí (remote)
    mode string Permisos (ex: '0644', '0755')
    owner string Propietari
    group string Grup
    backup bool Crea còpia de seguretat
    content string Contingut (en lloc de src)

    Exemples

    # Copiar fitxer
- name: Copiar configuració
  ansible.builtin.copy:
    src: /path/to/local/config.conf
    dest: /etc/myapp/config.conf
    owner: root
    group: root
    mode: '0644'
    backup: yes

# Crear fitxer amb contingut
- name: Crear fitxer de configuració
  ansible.builtin.copy:
    content: |
      [settings]
      debug=true
    dest: /etc/myapp/settings.conf

    ansible.builtin.file

    Gestiona fitxers, directoris i enllaços.

    Paràmetres Principals

    Paràmetre Tipus Descripció
    path string Camí del fitxer/directori
    state string file, directory, link, absent, touch
    mode string Permisos
    owner string Propietari
    group string Grup
    src string Origen (per enllaços)
    force bool Força creació/enllaç

    Estats

    Ús al Projecte

    # Crear directori .ssh
- name: Crear directori .ssh per a usuari
  ansible.builtin.file:
    path: /home/ansible/.ssh
    state: directory
    owner: ansible
    group: ansible
    mode: '0700'

# Assegurar authorized_keys
- name: Crear fitxer authorized_keys
  ansible.builtin.file:
    path: /home/ansible/.ssh/authorized_keys
    state: touch
    owner: ansible
    group: ansible
    mode: '0600'

    ansible.builtin.user

    Gestiona comptes d'usuari.

    Paràmetres Principals

    Paràmetre Tipus Descripció
    name string Nom de l'usuari
    state string present, absent
    password string Hash de la contrasenya
    shell string Shell per defecte
    home string Directori home
    groups list Grups addicionals
    append bool Afegir grups en lloc de substituir

    Ús al Projecte

    # linux_client.sh - Crear usuari ansible
- name: Crear usuari ansible sense password
  ansible.builtin.user:
    name: ansible
    password: ''
    shell: /bin/bash
    create_home: yes
    groups: sudo
    append: yes

    ansible.builtin.setup

    Recull informació del sistema (facts). S'executa automàticament al playbook.

    Categories d'informació (Facts)

    El sistema recull molta informació automàticament. Aquí tens les categories més importants:

    %%{init: {'theme': 'neutral'}}%%
mindmap
  root((Facts))
    Sistema
      ansible_distribution
      ansible_os_family
      ansible_kernel
      ansible_machine
    Xarxa
      ansible_default_ipv4
      ansible_all_ipv4_addresses
      ansible_hostname
      ansible_fqdn
    Hardware
      ansible_memtotal_mb
      ansible_processor_cores
      ansible_processor_vcpus
      ansible_devices
    Programari
      ansible_python_version
      ansible_pkg_mgr

    Ús

    # Recollir facts explícitament
- name: Recollir facts
  ansible.builtin.setup:
  register: facts

# Filtrar per subset
- name: Només facts de xarxa
  ansible.builtin.setup:
    gather_subset:
      - network

    Eines per a Windows

    Als ordinadors amb Windows fem servir eines molt semblants però adaptades al seu sistema. La més important és win_shell, que ens permet parlar amb el sistema de Microsoft per instal·lar programes o configurar serveis.

    ansible.windows.win_command

    Executa comandes de forma més segura que win_shell.

    # ✅ Millor per comandes simples
- name: Comprovar versió
  ansible.windows.win_command:
    cmd: cmd.exe /c ver

# ⚠️ Usar win_shell només si cal
- name: Executar script de PowerShell
  ansible.windows.win_shell: |
    Get-Service | Where-Object {$_.Status -eq 'Running'}

    ansible.windows.win_package

    Instal·la/desinstal·la paquets de software Windows.

    Paràmetres Principals

    Paràmetre Tipus Descripció
    path string Ruta de l'instal·lador
    product_id string GUID del producte
    arguments string Arguments de l'instal·lador
    state string present, absent 
    - name: Instal·lar aplicació des de MSI
  ansible.windows.win_package:
    path: C:\temp\app.msi
    state: present

    ansible.windows.win_service

    Gestiona serveis Windows.

    Paràmetres

    Paràmetre Tipus Descripció
    name string Nom del servei
    state string started, stopped, restarted
    enabled string auto, manual, disabled 
    - name: Assegurar que WinRM estigui actiu
  ansible.windows.win_service:
    name: WinRM
    state: started
    enabled: yes

    ansible.windows.win_copy

    Copia fitxers a hosts Windows.

    - name: Copiar fitxer
  ansible.windows.win_copy:
    src: /path/to/local/file.txt
    dest: C:\temp\file.txt

    ansible.windows.win_file

    Gestiona fitxers i directoris Windows.

    - name: Crear directori
  ansible.windows.win_file:
    path: C:\temp
    state: directory

    ansible.windows.win_regedit

    Gestiona el registre de Windows.

    - name: Afegir clau de registre
  ansible.windows.win_regedit:
    path: HKLM:\Software\MyApp
    name: version
    data: 1.0

    Mòduls de Xarxa

    ansible.builtin.wait_for

    Espera una condició abans de continuar.

    - name: Esperar que el port 22 estigui obert
  ansible.builtin.wait_for:
    port: 22
    host: "{{ inventory_hostname }}"
    delay: 5
    timeout: 300

    ansible.builtin.get_url

    Descarrega fitxers d'Internet.

    - name: Descarregar fitxer
  ansible.builtin.get_url:
    url: https://example.com/file.tar.gz
    dest: /tmp/file.tar.gz
    mode: '0644'

    ansible.builtin.uri

    Interacciona amb serveis web.

    - name: Fer petició HTTP
  ansible.builtin.uri:
    url: https://api.example.com/status
    method: GET
    return_content: yes

    Mòduls de Sistema

    ansible.builtin.cron

    Gestiona tasques programades (cron).

    - name: Afegir tasca cron
  ansible.builtin.cron:
    name: "Actualitzar diàriament"
    minute: "0"
    hour: "2"
    job: "apt-get update && apt-get upgrade -y"

    ansible.builtin.hostname

    Canvia el hostname del sistema.

    - name: Canviar hostname
  ansible.builtin.hostname:
    name: pc201

    ansible.builtin.reboot

    Reinicia el sistema.

    - name: Reiniciar i esperar
  ansible.builtin.reboot:
    reboot_timeout: 600

    Mòduls vs Funcionalitat del Projecte

    Funcionalitat Mòdul Linux Mòdul Windows
    Instal·lar apps apt win_shell (choco)
    Executar comandes shell win_shell
    Bloquejar webs shell (sed/iptables) N/A
    Control entrada shell (xinput) N/A
    Serveis systemd win_service
    Fitxers copy, file win_copy, win_file
    Usuaris user win_user
