    Guia per instal·lar el sistema

    Guia d'instal·lació completa del servidor i clients Ansible Web Manager.

    El procés d'instal·lació s'ha dissenyat per ser el més senzill possible. Tant el servidor com els clients disposen d'scripts automatitzats que preparen tot l'entorn. Básicament, només cal triar quin component es vol instal·lar (servidor, client Linux o client Windows), complir uns requisits mínims de sistema i executar l'script corresponent que s'encarrega d'instal·lar les dependències i configurar la seguretat.

    Instal·lació del Servidor

    El servidor és el "cervell" de l'aula. Perquè funcioni bé, necessitem un ordinador amb aquestes característiques: - Sistema Operatiu: Ubuntu (és el sistema que millor entén les nostres ordres). - Python: És el llenguatge que fem servir per parlar amb l'ordinador. - Memòria RAM: Com més en tingui, més ordinadors podrà controlar a la vegada. - Espai en disc: Per guardar els registres de tot el que passa a l'aula.

    Com es connecten els equips

    El sistema funciona com una estrella: el Servidor Ansible està al centre i es connecta a cada Client (ordinador de l'alumne) mitjançant un túnel segur (SSH per a Linux o WinRM per a Windows). El professor dóna les ordres des del seu navegador, el servidor les processa i les envia a tots els ordinadors seleccionats alhora.

    Com preparar i instal·lar el servidor

    Seguiu aquests passos per deixar el servidor a punt:

    1. Actualitza l'ordinador: Com la majoria de sistemes, primer cal descarregar les millores més recents amb sudo apt update.
    2. Instal·la les eines base: Necessitem alguns programes ajudants com curl o git per descarregar el projecte.
    3. Executa l'instal·lador: Entra a la carpeta del projecte i activa l'script amb ./install_server.sh. Aquest script farà tota la feina difícil per tu: instal·larà Ansible (el gestor), crearà claus de seguretat i prepararà la pàgina web.

    Proces d'Instal·lació

    L'script d'instal·lació del servidor segueix una seqüència lògica: primer verifica que s'està executant amb privilegis de root, després actualitza els repositoris del sistema i instal·la paquets crítics com Python i Ansible Core. Un cop instal·lada la base, descarrega les llibreries de Python necessàries (Flask i PyYAML), genera les claus SSH per a la comunicació segura, crea el fitxer de configuració global d'Ansible i, finalment, configura la webapp i el servei del sistema per a que s'iniciï automàticament.

    L'script realitza les següents accions:

    Pas Acció Descripció
    1 Actualitzar repositoris apt-get update
    2 Instal·lar paquets python3, ansible, openssh-server, git
    3 Instal·lar Python packages flask, pyyaml, requests
    4 Configurar claus SSH Generar o reutilitzar ansible_lab
    5 Crear configuració Ansible ansible.cfg
    6 Configurar webapp usuaris, inventaris
    7 Crear servei systemd ansible-web-manager.service

    Com iniciar i entrar a la web

    Una vegada instal·lat, ja pots començar a treballar:

    1. Engega el servei: Pots fer-ho manualment amb python3 app.py o deixar que el sistema ho faci sol.
    2. Obre el navegador: Entra a l'adreça http://localhost:8080.
    3. Identifica't: Escriu l'usuari i la contrasenya (per defecte són profe i profe).

    Obrir el navegador i anar a http://localhost:8080: - Usuari: profe - Contrasenya: profe

    ⚠️ Canviar contrasenya: Després del primer login, anar a /users per canviar-la.

    Troubleshooting - Servidor

    Error Causa Solució
    python3: command not found Python no instal·lat sudo apt install python3
    ImportError: No module named flask Paquets Python no instal·lats pip3 install flask pyyaml
    Permission denied No s'executa com a root Usar sudo
    Port 8080 already in use Port ja en ús sudo lsof -i :8080 i matar el procés
    Connection refused Servei no iniciat sudo systemctl start ansible-web-manager

    Instal·lació de Clients Linux

    Els clients són els ordinadors dels alumnes. Perquè el servidor els pugui controlar, hem de fer-los "amics":

    1. Descarrega l'ajudant: Agafa l'script linux_client.sh des del servidor.
    2. Prepara el fitxer: Dona-li permisos perquè es pugui executar (chmod +x).
    3. Instal·la el client: Executa l'script amb sudo ./linux_client.sh. Això instal·larà un sistema anomenat SSH, que és com un túnel segur perquè el servidor hi pugui entrar sense demanar contrasenya cada vegada.

    Proces d'Instal·lació del Client

    L'script linux_client.sh automatitza la preparació del client: verifica els permisos de root, actualitza el sistema, instal·la i activa el servidor SSH per permetre connexions remotes, crea l'usuari ansible (si no existeix), li atorga privilegis de sudo sense contrasenya i afegeix la clau pública del servidor per permetre l'accés sense intervenció manual.

    Com verificar que tot funciona

    És important comprovar que el servidor realment pot parlar amb el client:

    1. Prova la connexió: Des del servidor, escriu ssh ansible@<IP_DEL_CLIENT>. Si entres directament, és que tot ha anat bé.
    2. Afegeix-lo a la web: Entra a la pàgina de gestió i utilitza l'escaneig automàtic per trobar el nou ordinador i afegir-lo a la teva llista de classe.

    Troubleshooting - Client Linux

    Error Causa Solució
    Permission denied Clau SSH no afegida Reexecutar script o afegir manualment
    Connection refused SSH no actiu sudo systemctl start ssh
    Host key verification failed Clau host desconeguda ssh-keygen -R <IP> o esperar un moment
    sudo: no tty present Configuració sudo Revisar /etc/sudoers.d/ansible

    Instal·lació de Clients Windows

    Windows funciona una mica diferent, però el procés és gairebé el mateix:

    1. Obre el PowerShell: És la "caixa negra" de Windows. L'has d'obrir com a administrador.
    2. Dóna permisos: Escriu la comanda Set-ExecutionPolicy per permetre que Windows accepti el nostre script.
    3. Instal·la el client: Descarrega i executa windows_client.ps1. Això configurarà el protocol WinRM, que és el llenguatge que usa Windows per parlar amb el nostre servidor.

    Proces d'Instal·lació del Client Windows

    L'script de Windows realitza tasques similars però adaptades al sistema de Microsoft: abilita el protocol WinRM per a la gestió remota, configura les llistes de TrustedHosts per acceptar connexions del servidor, crea l'usuari administrador ansible, obre els ports necessaris al Firewall de Windows i configura l'autenticació bàsica per a la comunicació amb Ansible.

    Afegir a l'Inventari Windows

    # A ~/ansible_project/inventories/windows_inventory.ini
[windows]
win-pc01 ansible_host=192.168.203.50
win-pc02 ansible_host=192.168.203.51

[windows:vars]
ansible_user=ansible
ansible_password=Ansible123!
ansible_connection=winrm
ansible_winrm_transport=basic
ansible_winrm_server_cert_validation=ignore

    Verificar Connexió

    # Des del servidor
ansible windows -m win_ping -i ~/ansible_project/inventories/windows_inventory.ini

# Ha de retornar:
# win-pc01 | SUCCESS => {

    Configurar Firewall

    # Obrir port 8080
sudo ufw allow 8080/tcp

# Obrir port 22 (SSH)
sudo ufw allow 22/tcp

# Activar firewall
sudo ufw enable

    Accés des d'Altres Màquines

    # Permetre accés des de tota la xarxa local
sudo ufw allow from 192.168.0.0/16 to any port 8080

# O des de IP específiques
sudo ufw allow from 192.168.1.0/24 to any port 8080

    Verificació Final

    Checklist de Verificació

    El procés de verificació final assegura que tot l'ecosistema funcioni correctament. Comença comprovant l'estat del servidor, seguit de la verificació dels clients. Un cop confirmada la connectivitat bàsica, es realitzen tests d'accés web i de comunicació Ansible (ping) per garantir que el sistema estigui completament llest per per ser utilitzat a l'aula.

    Test Comanda Resultat Esperat
    Versió Python python3 --version Python 3.8+
    Versió Ansible ansible --version ansible 2.12+
    Clau SSH ls -la ~/.ssh/ansible_lab Fitxer existeix
    Config Ansible cat ansible.cfg Fitxer existeix
    Servei Web curl http://localhost:8080 Resposta HTML
    Connexió Client ssh -i ~/.ssh/ansible_lab ansible@pc201 whoami "ansible"
    Ping Ansible ansible pc201 -m ping "pong"

    Test Complet

    Annex: Apte Automàtic

    #!/bin/bash
# Script de verificació automàtica

echo "=== Verificant Servidor Ansible ==="

# Test 1: Python
if command -v python3 &> /dev/null; then
    echo "✅ Python: $(python3 --version)"
else
    echo "❌ Python no trobat"
fi

# Test 2: Ansible
if command -v ansible &> /dev/null; then
    echo "✅ Ansible: $(ansible --version | head -1)"
else
    echo "❌ Ansible no trobat"
fi

# Test 3: Clau SSH
if [ -f ~/.ssh/ansible_lab ]; then
    echo "✅ Clau SSH existeix"
else
    echo "❌ Clau SSH no trobada"
fi

# Test 4: Servei web
if curl -s http://localhost:8080 > /dev/null; then
    echo "✅ Servei web actiu"
else
    echo "❌ Servei web no respon"
fi

# Test 5: Inventari
if [ -f ~/ansible_project/inventories/inventory.ini ]; then
    echo "✅ Inventari existeix"
else
    echo "❌ Inventari no trobat"
fi

echo "=== Verificació Completada ==="
