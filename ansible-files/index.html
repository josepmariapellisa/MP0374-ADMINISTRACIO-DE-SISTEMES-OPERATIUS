    On es guarden les dades: els fitxers d'Ansible

    Documentació dels fitxers d'Ansible per a personalització i manteniment.

    Com s'organitzen les carpetes

    ansible_project/
├── ansible.cfg              # Configuració global d'Ansible
├── inventories/
│   ├── inventory.ini        # Inventari de hosts Linux
│   └── windows_inventory.ini # Inventari de hosts Windows
├── playbooks/
│   ├── apps.yml             # Playbook d'instal·lació d'apps Linux
│   ├── windows_apps.yml     # Playbook d'instal·lació d'apps Windows
│   └── base.yml             # Configuració base d'hosts
└── group_vars/
    └── alumnes/
        ├── apps.yml         # Variables per a apps Linux
        └── windows_apps.yml # Variables per a apps Windows

    L'estructura de directoris està pensada per separar clarament la configuració (ansible.cfg), la definició d'equips (inventaris) i la lògica d'execució (playbooks). Les variables es guarden apart a group_vars per permetre personalitzacions sense haver de modificar els playbooks principals.

    L'arxiu de configuració general (ansible.cfg)

    Aquest fitxer és el que diu a Ansible com ha de treballar. És com el llibre de regles del joc:

    • On són els ordinadors: Indica quin fitxer d'inventari ha de mirar per saber quins ordinadors hi ha a l'aula.
    • Seguretat: Li diu quina clau secreta ha de fer servir per connectar-se amb els alumnes.
    • Temps d'espera: Defineix quant de temps ha d'esperar si un ordinador triga a respondre.
    [defaults]
host_key_checking = False
inventory = inventories/inventory.ini
private_key_file = ~/.ssh/ansible_lab
remote_user = ansible
timeout = 30
gathering = smart
fact_caching = jsonfile
fact_caching_connection = /tmp/ansible_facts
fact_caching_timeout = 3600

[ssh_connection]
pipelining = True

    Paràmetres Clau

    Paràmetre Descripció Per Canviar
    inventory Inventari per defecte Si vols usar un altre inventari
    private_key_file Clau SSH per defecte Si la teva clau és en un altre lloc
    timeout Timeout en segons Augmenta si tens connexions lentes
    host_key_checking Verificació clau host Mantingues a False per automatització

    On Fer Canvis

    # Si vols canviar la clau SSH:
# Edita la línia private_key_file
nano ~/ansible_project/ansible.cfg

# Si vols un altre inventari per defecte:
# Edita la línia inventory

    Les llistes d'ordinadors (Inventaris)

    L'inventari és una llista simple on escrivim les adreces (IP) de cada ordinador de l'aula.

    • Fitxer per a Linux: Es diu inventory.ini i conté els ordinadors que usen Ubuntu.
    • Fitxer per a Windows: Es diu windows_inventory.ini i serveix per als ordinadors amb Windows.
    • Com afegir-ne un: Pots fer-ho a mà editant el fitxer o a través de la web fent un escaneig de xarxa.

    inventory.ini (Linux)

    [alumnes]
pc201 ansible_host=192.168.203.201
pc202 ansible_host=192.168.203.202
pc203 ansible_host=192.168.203.203

[alumnes:vars]
ansible_user=ansible
ansible_ssh_private_key_file=~/.ssh/ansible_lab
ansible_become=true

    Seccions

    Secció Descripció Exemple
    [alumnes] Grup d'hosts pc201 ansible_host=192.168.203.201
    [alumnes:vars] Variables del grup ansible_user=ansible

    Afegir un Host

    # Opció 1: Manual
echo "pc204 ansible_host=192.168.203.204" >> ~/ansible_project/inventories/inventory.ini

# Opció 2: Via web
# Clic "Escanejar xarxa" → Selecciona hosts → "Afegir seleccionats"

    windows_inventory.ini

    [windows]
win-pc01 ansible_host=192.168.203.50
win-pc02 ansible_host=192.168.203.51

[windows:vars]
ansible_user=ansible
ansible_password=Ansible123!
ansible_connection=winrm
ansible_winrm_transport=basic
ansible_winrm_server_cert_validation=ignore

    On Fer Canvis

    # Per afegir hosts manualment:
nano ~/ansible_project/inventories/inventory.ini

# Per afegir hosts Windows:
nano ~/ansible_project/inventories/windows_inventory.ini

    Els llibres d'instruccions (Playbooks)

    Un "Playbook" és una llista de tasques que volem que Ansible faci. Per exemple: "Primer actualitza l'ordinador i després instal·la el VLC".

    • Lliçons per a Linux: El fitxer principal és apps.yml.
    • Lliçons per a Windows: Fem servir windows_apps.yml.
    • Com funcionen: Es llegeixen d'adalt a avall, fent una tasca darrera de l'altre fins que s'acaben totes.

    apps.yml (Linux)

    Playbook per instal·lar aplicacions en hosts Linux.

    ---
- name: Instal·lar aplicacions seleccionades
  hosts: alumnes
  become: true

  pre_tasks:
    - name: Reparar dependències trencades (dpkg)
      command: dpkg --configure -a
      changed_when: false
      ignore_errors: true

    - name: Actualitzar cache APT
      apt:
        update_cache: yes
        cache_valid_time: 300

  tasks:
    - name: Instal·lar aplicacions del catàleg
      apt:
        name: "{{ item }}"
        state: present
        update_cache: yes
      loop: "{{ selected_apps }}"
      when: selected_apps | length > 0

    - name: Instal·lar paquets APT personalitzats
      apt:
        name: "{{ item }}"
        state: present
      loop: "{{ custom_apt_packages }}"
      when: custom_apt_packages | length > 0

    Estructura del Playbook

    Un playbook típic segueix una estructura seqüencial d'execució: primer es realitzen les tasques prèvies de manteniment (com actualitzar el catàleg de paquets APT), i després es procedeix amb la instal·lació de les aplicacions realment seleccionades a la web, garantint que el sistema estigui en un estat òptim abans de fer canvis.

    On Fer Canvis

    # Si vols afegir tasques prèvies:
nano ~/ansible_project/playbooks/apps.yml
# Afegeix sota la secció pre_tasks

# Si vols modificar com s'instal·len les apps:
# Edita la secció tasks

    windows_apps.yml

    Playbook per instal·lar aplicacions en hosts Windows via Chocolatey.

    ---
- name: Instal·lar aplicacions seleccionades (Windows via Chocolatey)
  hosts: windows
  gather_facts: false
  tasks:
    - name: Instal·lar aplicacions del catàleg
      ansible.windows.win_shell: "choco install {{ item }} -y"
      loop: "{{ selected_apps }}"
      when: selected_apps | length > 0

    On Fer Canvis

    # Si vols usar un altre gestor de paquets:
nano ~/ansible_project/playbooks/windows_apps.yml
# Canvia 'choco install' per 'winget install' o altres

# Si vols afegir tasques addicionals:
# Afegeix sota la secció tasks

    Personalització i variables

    Les variables són com "espais buits" que omplim amb informació a l'últim moment. Per exemple, podem tenir una llista de programes que volem instal·lar.

    • Variables de classe: Es guarden a la carpeta group_vars.
    • Per què serveixen?: Així no hem de tocar el fitxer de playbooks cada vegada que vulguem canviar un programa; només canviem la llista de variables.

    group_vars/alumnes/apps.yml

    Variables per a la instal·lació d'apps Linux.

    custom_apt_packages: []
selected_apps:
  - gimp
  - filezilla

    Variables Disponibles

    Variable Tipus Descripció
    selected_apps llista Apps a instal·lar des del catàleg
    custom_apt_packages llista Paquets APT personalitzats

    On Fer Canvis

    # Aquest fitxer es modifica automàticament per la web
# Però pots editarlo manualment:
nano ~/ansible_project/group_vars/alumnes/apps.yml

# Per afegir paquets personalitzats que sempre s'instal·lin:
custom_apt_packages:
  - vim
  - htop
  - tree

    group_vars/alumnes/windows_apps.yml

    Variables per a la instal·lació d'apps Windows.

    custom_choco_packages: []
selected_apps: []

    On Fer Canvis

    # Per afegir paquets personalitzats:
nano ~/ansible_project/group_vars/alumnes/windows_apps.yml

custom_choco_packages:
  - vscode
  - notepadplusplus

    Personalització Comú

    Afegir una Nova Tarea a Tots els Hosts

    # Edita base.yml o afegeix a apps.yml
nano ~/ansible_project/playbooks/apps.yml

# Afegeix sota la secció tasks:
- name: La meva tasca personalitzada
  <modul_ansible>:
    <paràmetres>

    Canviar el Mètode d'Instal·lació

    # Per usar un altre gestor de paquets (ex: flatpak):
nano ~/ansible_project/playbooks/apps.yml

- name: Instal·lar via Flatpak
  flatpak:
    name: "{{ item }}"
    state: present
  loop: "{{ selected_flatpaks }}"

    Afegir un Nou Inventari

    # Crea un nou inventari per a un altre grup
nano ~/ansible_project/inventories/professors.ini

[professors]
prof1 ansible_host=192.168.1.100
prof2 ansible_host=192.168.1.101

[professors:vars]
ansible_user=ansible
ansible_ssh_private_key_file=~/.ssh/ansible_lab
ansible_become=true

    Canviar el Grup per Defecte

    # Si vols que els playbooks s'executin en un altre grup:
nano ~/ansible_project/playbooks/apps.yml

# Canvia la línia hosts:
hosts: professors  # En lloc d'alumnes

    Provar Canvis

    Provar un Playbook

    # Prova sense fer canvis (dry-run)
ansible-playbook playbooks/apps.yml --check

# Prova només en un host
ansible-playbook playbooks/apps.yml --limit pc201

# Prova amb verbose
ansible-playbook playbooks/apps.yml -v

    Provar una Tasta

    # Provar un mòdul Ansible directament
ansible pc201 -m apt -a "name=vlc state=present"

# Provar un comandament
ansible pc201 -m shell -a "whoami"
